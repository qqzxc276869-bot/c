# C语言中变量、地址、指针以及 `*` 和 `&` 的层级关系

> 本文采用下面这个学习约定：**变量中最终保存的数据值在最高层，变量的地址在较低层。**  
> 按照这个约定，表达式中的 `*` 是“沿地址找到对象”，所以向上走一层；表达式中的 `&` 是“取得对象的地址”，所以向下走一层。

---

## 一、先给出最重要的结论

假设有下面的代码：

```c
int x = 10;
int *p = &x;
int **pp = &p;
```

可以画成：

```text
较低层                                                   较高层

pp中保存的地址 ──*──> p中保存的地址 ──*──> x中保存的值10
     &p                    &x

pp == &p
*pp == p == &x
**pp == *p == x == 10
```

按照本文规定的层级方向：

| 运算 | 含义 | 层级变化 |
| --- | --- | --- |
| `&变量` | 取得这个变量的地址 | **下降一层** |
| `*地址` | 根据地址找到该地址所指的变量 | **上升一层** |
| `**地址` | 连续解引用两次 | **上升两层** |
| `&&变量` | 在C语言表达式中不能这样连续取地址 | 不是合法的普通写法 |

一句话记忆：

```text
&：从“房间”退到“门牌号”，下降一层。
*：拿着“门牌号”进入“房间”，上升一层。
```

但是要注意：这里说的“上升、下降”只是帮助理解指针关系的模型，不是C语言标准里的正式术语。

### 特别注意：这里其实有两套不同的“层级说法”

这两套说法不能混成一套，否则会觉得结论互相矛盾。

| 层级说法 | `&` 的变化 | `*` 的变化 |
| --- | --- | --- |
| 本文按你规定的“值在上、地址在下”的位置模型 | 向下走一层 | 向上走一层 |
| C语言常说的“几级指针类型” | 指针级数加一 | 指针级数减一 |

例如：

```text
x的类型是int
&x的类型是int *
```

从你规定的位置模型看，`x → &x` 是从值走向地址，所以是**向下**；从类型名称看，`int → int *` 是从非指针变成一级指针，所以是**指针级数加一**。

这并不矛盾，因为两者回答的是不同问题：

```text
“向上还是向下”描述沿着对象和地址往哪个方向走；
“一级、二级、三级指针”描述类型中有多少层间接关系。
```

## 二、必须分清的四样东西

很多混淆并不是因为 `*` 和 `&` 本身难，而是把下面四样东西混成了一样。

```c
int x = 10;
int *p = &x;
```

### 1. 普通变量 `x`

`x` 是一个真实存在的 `int` 对象，它占用一块内存，里面保存整数 `10`。

```text
变量名：x
变量类型：int
变量的值：10
变量的地址：&x
```

### 2. `x` 的地址 `&x`

`&x` 不是 `x` 中保存的整数，而是 `x` 所在内存位置的地址。

```text
x     → 整数10
&x    → x的地址
```

若假设 `x` 恰好位于地址 `0x1000`：

```text
x  的结果是 10
&x 的结果是 0x1000
```

实际地址由程序运行时决定，这里只是假设的示意地址。

### 3. 指针变量 `p`

`p` 也是一个真实变量，也占用自己的内存。区别只是：普通整数变量保存整数，指针变量保存地址。

```c
int *p = &x;
```

这行执行后：

```text
p中保存的值 = &x = x的地址
```

所以：

```text
p和&x的“地址值”相等
```

但 `p` 和 `x` 不是同一个变量。`p` 是指针变量，`x` 是普通整数变量。

### 4. 指针变量自己的地址 `&p`

因为 `p` 自己也是变量，所以它也有地址：

```text
p     → p中保存的值，也就是x的地址
&p    → p这个指针变量自身的地址
```

假设：

```text
x位于0x1000
p位于0x2000
```

那么：

```text
x   == 10
&x  == 0x1000
p   == 0x1000
&p  == 0x2000
*p  == 10
```

最容易混淆的是：

```text
p  是“p中保存的地址”；
&p 是“p自己所在的地址”。
```

## 三、用你的“最高层和最低层”理解 `&`

### 1. `&` 对变量做了什么

表达式中的一元 `&` 叫作**取地址运算符**。

```c
&x
```

它不会读取 `x` 里面保存的整数作为结果，而是取得 `x` 这个对象所在的位置。

若把值看成上层、地址看成下层：

```text
x  ──&──>  &x
值层        地址层
高          低
```

因此，在本文的层级约定中：

> `&` 对变量执行“取地址”，使结果下降一层。

### 2. `&` 会改变变量吗

不会。

```c
int x = 10;
int *p = &x;
```

`&x` 只是取得 `x` 的地址：

- 不会把 `x` 变成指针；
- 不会修改 `x` 的值；
- 不会复制一个新的 `x`；
- 只是产生一个指向 `x` 的地址结果。

### 3. `&` 之后类型如何变化

```text
x    的类型是 int
&x   的类型是 int *
```

再看指针变量 `p`：

```text
p    的类型是 int *
&p   的类型是 int **
```

所以可以把类型变化记为：

```text
T  ──&──>  T *
```

例如：

```text
int       ──&──> int *
int *     ──&──> int **
int **    ──&──> int ***
```

每取一次地址，结果就多一级指针。

## 四、用你的“最高层和最低层”理解 `*`

### 1. `*` 对地址做了什么

表达式中的一元 `*` 叫作**解引用运算符**或**间接访问运算符**。

```c
*p
```

它的意思不是“读取 `p` 自己所在的位置”，而是：

1. 先取出 `p` 中保存的地址；
2. 沿着这个地址找到它指向的对象；
3. 用 `*p` 表示这个对象。

```text
p中保存x的地址  ──*──>  x这个对象
地址层                    值层
低                        高
```

因此，在本文的层级约定中：

> `*` 对一个有效地址执行“解引用”，使结果上升一层。

### 2. `*p` 不只是得到数值，还能代表原变量

这是特别重要的一点：`*p` 不仅可以读取 `x` 的值，它还可以直接代表 `x` 这个对象。

```c
int x = 10;
int *p = &x;

printf("%d\n", *p);  // 读取x，输出10
*p = 50;              // 修改x
printf("%d\n", x);   // 输出50
```

因为 `p` 指向 `x`，所以：

```text
*p就是p所指的x
```

执行 `*p = 50;` 时，并不是把 `p` 改成 `50`，而是把 `p` 所指对象 `x` 改成 `50`。

### 3. `*` 之后类型如何变化

如果 `p` 的类型是 `int *`：

```text
p     的类型是 int *
*p    表示的对象类型是 int
```

如果 `pp` 的类型是 `int **`：

```text
pp     的类型是 int **
*pp    表示的对象类型是 int *
**pp   表示的对象类型是 int
```

所以可以把类型变化记为：

```text
T *  ──*──>  T
```

例如：

```text
int ***   ──*──> int **
int **    ──*──> int *
int *     ──*──> int
```

每解引用一次，结果就少一级指针。

## 五、完整的层级图：`x`、`p`、`pp`

```c
int x = 10;
int *p = &x;
int **pp = &p;
```

假设：

```text
x位于地址0x1000
p位于地址0x2000
pp位于地址0x3000
```

那么各变量的内存可以想象成：

```text
地址0x3000：变量pp，里面保存0x2000
地址0x2000：变量p， 里面保存0x1000
地址0x1000：变量x， 里面保存10
```

沿着 `*` 向上：

```text
pp       == 0x2000
*pp      == p       == 0x1000
**pp     == *p      == x       == 10
```

沿着 `&` 向下：

```text
x   ──&──> &x，&x可以保存到p中
p   ──&──> &p，&p可以保存到pp中
pp  ──&──> &pp，&pp需要用int ***类型的指针保存
```

可以整理成下面的表格：

| 表达式 | 含义 | 类型 | 假设的结果 |
| --- | --- | --- | --- |
| `x` | 整数变量 `x` 的值 | `int` | `10` |
| `&x` | `x` 的地址 | `int *` | `0x1000` |
| `p` | `p` 中保存的地址 | `int *` | `0x1000` |
| `*p` | `p` 指向的对象，也就是 `x` | `int` | `10` |
| `&p` | 指针变量 `p` 自己的地址 | `int **` | `0x2000` |
| `pp` | `pp` 中保存的地址 | `int **` | `0x2000` |
| `*pp` | `pp` 指向的对象，也就是 `p` | `int *` | `0x1000` |
| `**pp` | 先找到 `p`，再找到 `x` | `int` | `10` |
| `&pp` | 指针变量 `pp` 自己的地址 | `int ***` | `0x3000` |

这里可以发现：

```text
p   与 &x 的地址值相等，但表达式来源不同；
pp  与 &p 的地址值相等；
*p、**pp 和 x 都表示同一个int对象。
```

## 六、`*` 和 `&` 为什么说是相反操作

### 1. `*&x` 等于什么

从 `x` 开始：

```text
x ──&──> &x ──*──> x
    下降       上升
```

所以：

```c
*&x
```

最终仍然表示 `x` 这个对象。

```c
int x = 10;
*&x = 30;
```

等价于：

```c
x = 30;
```

### 2. `&*p` 等于什么

如果 `p` 指向一个有效对象：

```text
p ──*──> *p ──&──> p
    上升       下降
```

所以：

```c
&*p
```

得到的地址与 `p` 保存的地址相同。

### 3. 可以机械地消掉相邻的 `*&` 和 `&*` 吗

在最基础、对象和指针都有效的例子里，可以用“相邻反操作”来理解：

```text
*&x  → x
&*p  → p
```

但不要脱离合法性只做符号消除：

- `*p` 要求 `p` 是能够指向相应对象的有效指针；
- 空指针、野指针、悬空指针都不能拿来正常解引用；
- 复杂表达式还涉及类型、数组和运算符规则，不能只看符号外形。

## 七、为什么 `p` 有时像“地址”，有时又是“变量”

这是最常见的困惑。

```c
int x = 10;
int *p = &x;
```

从两个角度看 `p`：

### 角度一：看 `p` 里面保存的内容

单独写 `p` 时，表达式通常取得 `p` 中保存的值。因为 `p` 是指针变量，所以这个值是地址：

```text
p == &x
```

### 角度二：把 `p` 看成内存中的一个对象

`p` 自己也占内存，所以可以对它取地址：

```text
&p == pp
```

因此完全不矛盾：

```text
p是一个变量；
p这个变量里保存的值恰好是地址；
p自己也有另一个地址& p（正确写法为&p）。
```

可以类比成一张纸条：

- `p` 是一张真实存在的纸条；
- 纸条上写着 `x` 的门牌号；
- `p` 表达式读出纸条上的门牌号；
- `&p` 是这张纸条自己放在哪里；
- `*p` 是按照纸条上的门牌号找到 `x`。

---

## 八、声明中的 `*` 和表达式中的 `*` 不是同一个动作

### 1. 声明中的 `*`

```c
int *p;
```

这里的 `*` 用于声明：`p` 是一个指向 `int` 的指针变量。

此时没有执行“上升一层”的操作，也没有访问任何对象。

### 2. 表达式中的 `*`

```c
int x = *p;
```

这里的 `*` 才是解引用：沿着 `p` 保存的地址找到所指对象。

### 3. 两个操作数之间的 `*`

```c
int result = a * b;
```

这里的 `*` 是乘法，与指针解引用没有关系。

必须根据位置判断：

| 写法 | `*` 的含义 |
| --- | --- |
| `int *p;` | 声明 `p` 是指针 |
| `value = *p;` | 解引用 `p` |
| `a * b` | 乘法 |

---

## 九、表达式中的 `&` 和其他位置的 `&` 也要区分

### 1. 一元 `&`：取地址

```c
p = &x;
```

这里 `&` 只有右边一个操作数，表示取得 `x` 的地址。

### 2. 二元 `&`：按位与

```c
result = a & b;
```

这里 `&` 左右各有一个操作数，表示按位与，不是取地址。

例如：

```text
6      = 110（二进制）
3      = 011（二进制）
6 & 3  = 010（二进制）= 2
```

### 3. `&&`：逻辑与

```c
if (a > 0 && b > 0) {
    /* a和b都大于0 */
}
```

`&&` 是逻辑与，也不是“连续取两次地址”。

| 写法 | 含义 |
| --- | --- |
| `&x` | 取 `x` 的地址 |
| `a & b` | 按位与 |
| `a && b` | 逻辑与 |

## 十、左边和右边：读取与修改为什么不一样

### 1. `*p` 放在赋值号右边

```c
int y = *p;
```

表示读取 `p` 所指对象的值，再把这个值赋给 `y`。

若 `p` 指向 `x`，就相当于：

```c
int y = x;
```

### 2. `*p` 放在赋值号左边

```c
*p = 50;
```

表示把 `p` 所指对象修改为 `50`。

若 `p` 指向 `x`，就相当于：

```c
x = 50;
```

### 3. `p = &y` 又是什么

```c
p = &y;
```

这是修改 `p` 自己保存的地址，让 `p` 改为指向 `y`。它不会自动修改 `x` 或 `y` 中的值。

对比：

| 语句 | 被修改的对象 | 结果 |
| --- | --- | --- |
| `*p = 50;` | `p` 指向的变量 | 修改目标变量的值 |
| `p = &y;` | 指针变量 `p` | 改变 `p` 的指向 |

## 十一、`scanf` 为什么经常要写 `&变量`

```c
int x;
scanf("%d", &x);
```

`scanf` 需要修改调用者的变量 `x`，所以它需要知道 `x` 在哪里。`&x` 把 `x` 的地址传给函数。

可以简化理解为：

```text
调用者：用&x把x的地址交给scanf，层级下降一层。
scanf内部：通过收到的地址找到x并写入，概念上用*上升一层。
```

类似的自定义函数：

```c
void set_value(int *p)
{
    *p = 100;
}

int main(void)
{
    int x = 10;
    set_value(&x);
    return 0;
}
```

过程是：

```text
x ──&──> &x ──传给p──> p ──*──> x
```

`&x` 负责提供地址，`*p` 负责沿地址找到并修改原变量。

不过字符串数组是一个需要单独学习的场景。例如：

```c
char name[20];
scanf("%19s", name);
```

这里数组名 `name` 在该函数调用表达式中会转换成首元素地址，所以通常不再写 `&name`。

## 十二、二级指针为什么存在

如果函数只拿到一级指针的副本，它可以通过这个地址修改目标值，却不能仅靠给形参重新赋值来改变调用者的指针变量。

### 1. 一级指针可以修改普通变量

```c
void change_value(int *p)
{
    *p = 100;
}
```

这里：

```text
p ──*──> 普通int变量
```

### 2. 二级指针可以修改指针变量

```c
void change_pointer(int **pp, int *new_address)
{
    *pp = new_address;
}

int main(void)
{
    int x = 10;
    int y = 20;
    int *p = &x;

    change_pointer(&p, &y);
    /* 现在p指向y */
    return 0;
}
```

层级过程：

```text
&p       得到指针变量p自己的地址，下降一层；
pp       接收&p；
*pp      上升一层，表示调用者的指针变量p；
*pp=&y   修改p中保存的地址，使p改为指向y。
```

因此：

```text
想通过函数修改普通int变量 → 传int *，使用*p。
想通过函数修改int *指针变量 → 传int **，使用*pp。
```

## 十三、层级判断的可靠方法：不要只数星号，要先写类型

遇到复杂代码时，按下面顺序判断。

### 第一步：写出每个变量的声明类型

```c
int x;
int *p;
int **pp;
```

```text
x  ：int
p  ：int *
pp ：int **
```

### 第二步：每遇到一个表达式 `&`，类型增加一级指针

```text
x    ：int
&x   ：int *

p    ：int *
&p   ：int **
```

### 第三步：每遇到一个合法的表达式 `*`，类型减少一级指针

```text
pp    ：int **
*pp   ：int *
**pp  ：int
```

### 第四步：再问“这个表达式最终代表谁”

```c
int x = 10;
int *p = &x;
int **pp = &p;
```

```text
*p    代表x
*pp   代表p
**pp  代表x
```

类型能对应上，层级关系通常就不会判断错。

## 十四、不能解引用的指针

“`*` 向上走一层”有一个前提：这个指针必须能合法地指向一个仍然存在、类型也适合访问的对象。

### 1. 空指针

```c
int *p = NULL;
/* printf("%d", *p); */  /* 错误：不能解引用空指针 */
```

`NULL` 表示当前没有指向可访问对象。

### 2. 未初始化的指针

```c
int *p;
/* *p = 10; */  /* 错误：p中是不确定的地址 */
```

### 3. 悬空指针

```c
int *p = malloc(sizeof *p);
if (p != NULL) {
    *p = 10;
    free(p);
    p = NULL;
}
```

内存释放后，原地址不再能够作为原对象继续解引用。把当前指针设为 `NULL` 可以减少误用，但其他保存同一旧地址的指针不会自动变成 `NULL`。

所以，不要把 `*` 理解成“任何数字前加星号都能上升”。只有合适类型的有效指针才能被正常解引用。

## 十五、常见混淆逐条纠正

### 混淆1：指针就是地址

不够准确。

更准确地说：

```text
地址是一个内存位置的信息；
指针值是一种带有指向类型含义的地址值；
指针变量是专门保存指针值的变量。
```

### 混淆2：`p` 就是 `&p`

错误。

```text
p  ：p中保存的地址，即它所指对象的地址；
&p ：p这个指针变量自己的地址。
```

### 混淆3：`*p` 会改变 `p`

不一定。`*p` 是访问 `p` 指向的对象。

```c
*p = 20;  // 修改目标对象
p = &y;   // 修改p自己的指向
```

### 混淆4：`&x` 会把 `x` 变成指针

错误。`x` 仍然是 `int` 变量，只是表达式 `&x` 的结果类型为 `int *`。

### 混淆5：有几个 `*` 就一定是几级指针

要先看它是在声明中还是表达式中。

```c
int **pp;  // 声明pp为二级指针
**pp = 5; // 表达式中连续解引用两次
```

两处星号的作用不同，只是类型关系互相对应。

### 混淆6：`int *p, q;` 中两者都是指针

错误，只有 `p` 是指针：

```c
int *p;
int q;
```

如果想定义两个指针，初学时建议分开写：

```c
int *p;
int *q;
```

### 混淆7：地址越大，层级就越高

错误。这里的“层级高低”描述的是指向关系，不是地址数值的大小。

```text
0x3000不一定比0x1000“层级高”；
它们只是两个数值不同的内存地址。
```

## 十六、完整可运行示例

```c
#include <stdio.h>

int main(void)
{
    int x = 10;
    int *p = &x;
    int **pp = &p;

    printf("x     = %d\n", x);
    printf("&x    = %p\n", (void *)&x);

    printf("p     = %p\n", (void *)p);
    printf("*p    = %d\n", *p);
    printf("&p    = %p\n", (void *)&p);

    printf("pp    = %p\n", (void *)pp);
    printf("*pp   = %p\n", (void *)*pp);
    printf("**pp  = %d\n", **pp);
    printf("&pp   = %p\n", (void *)&pp);

    *p = 20;
    printf("修改*p后：x = %d\n", x);

    **pp = 30;
    printf("修改**pp后：x = %d\n", x);

    return 0;
}
```

地址每次运行可能不同，但必定可以观察到下面的关系：

```text
&x和p打印出的地址相同；
&p和pp打印出的地址相同；
p和*pp打印出的地址相同；
x、*p和**pp访问的是同一个int对象；
修改*p或**pp，最后看到的x都会变化。
```

## 十七、用一道题检查是否真正理解

```c
int a = 5;
int *p = &a;
int **pp = &p;
```

### 问题1：谁保存 `a` 的地址

答案：

```text
&a是a的地址；
p中保存的值也是a的地址；
*pp表示p，所以*pp的值也是a的地址。
```

即：

```text
p == &a
*pp == p
```

### 问题2：谁能访问整数 `5`

答案：

```text
a、*p和**pp都访问同一个int对象。
```

### 问题3：`&p` 是谁的地址

答案：`&p` 是指针变量 `p` 自己的地址，不是 `a` 的地址。

```text
pp == &p
```

### 问题4：执行 `**pp = 100;` 后谁改变了

最终改变的是 `a` 所代表的那个 `int` 对象：

```text
**pp → *p → a
```

所以 `a` 变成 `100`。`p` 仍然指向 `a`，`pp` 仍然指向 `p`。

## 十八、最终总结

采用“值最高、地址最低”的约定时，可以这样记：

```text
&：取得当前对象的地址，下降一层，类型多一个*。
*：沿当前地址找到所指对象，上升一层，类型少一个*。
```

最基础的关系是：

```text
x ──&──> &x
       地址下降一层

p ──*──> *p
       解引用上升一层
```

如果 `p = &x`，那么：

```text
p == &x
*p表示x
&p是p自己的地址
```

如果再有 `pp = &p`，那么：

```text
pp == &p
*pp表示p
**pp表示x
```

最后请牢牢记住三个判断问题：

1. **这个符号是在声明里，还是在表达式里？**
2. **这个变量里面保存的是普通值，还是地址？**
3. **现在要找的是目标变量、目标变量的地址，还是指针变量自己的地址？**

只要每一步都先写出类型，再顺着 `&` 向下、顺着 `*` 向上，就不容易把 `x`、`&x`、`p`、`*p` 和 `&p` 混在一起。
