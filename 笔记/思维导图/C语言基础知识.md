# C 语言基础知识思维导图

## 一、C 语言的认知

- **概念**：C 语言是编程语言的一种，用于人和机器进行交流
- **应用领域**：系统软件、嵌入式开发、游戏开发、网络编程
- **编程环境**
  - Windows 下：开发工具如 Visual Studio 等
  - Linux 系统下：vim 编辑器或者 VSCode

## 二、变量

- **定义**：存储数据的容器
- **注意点**：变量名的命名规则
- **使用**：定义和赋值
- **面试题：变量的定义和变量的声明的区别**
  1. 变量的定义不可以重复，声明可以多次声明
  2. 定义变量时会分配内存空间，声明时不会分配内存空间

## 四、数据类型长度

1. 使用 `sizeof()` 可以获取某种数据类型或变量所占内存大小

## 六、常量

1. **特点**：值不可改变，只读性
2. **分类**
   - 直接常量
   - 自定义常量
   - 系统定义常量
3. **自定义常量**
   - `#define` 定义的宏常量
   - `const` 关键字定义的常量
   - **面试题：两种自定义常量的区别**
     - **共同点**：都是常量不可更改，只读性
     - **不同点**
       1. `#define` 一般定义在函数的外部，`const` 常量定义在函数体内部
       2. `#define` 常量的原理是字符串的替换（宏替换），`const` 常量需要分配内存空间，存储的数据是只读的

## 七、数值的存储方式

- 非负数以原码存储
- 负数以补码存储
- 8 进制、16 进制的数以原码存储

## 八、输入输出语句

- 输出字符串：`printf("hello world ");`
- 输出变量：`printf("a=%d", a);`
- 输入：`scanf("%d %d", &num1, &num2);`

## 九、运算符

### 1. 算术运算符

`+` `-` `*` `/` `%` `++` `--`

- 注意：`++a`（前置 ++）先加 1，再返回值；`a++`（后置 ++）先返回值，再加 1。`--` 同理

### 2. 赋值运算符

`=` `+=` `-=` `*=` `/=` `%=`

- 例如：`a += 2` 等价于 `a = a + 2`

### 3. 比较运算符

`==` `!=` `>` `<` `>=` `<=`

- 返回值是 0 或者 1

### 4. 逻辑运算符

- 逻辑非 `!`：非真即假，非假即真
- 逻辑与 `&&`：同真即真，否则为假
- 逻辑或 `||`：同假即假，否则为真
- **注意：短路与和短路或**，符号两端是表达式时会出现短路情况
  - 短路与 `&&`：左边为真，右边执行；左边为假，右边不执行
  - 短路或 `||`：左边为真，右边不执行；左边为假，右边执行

### 5. 位运算符

- 按位与 `&`：同为 1，其余为 0
- 按位或 `|`：只要有 1 就是 1，其余是 0
- 按位异或 `^`：相同为 0，不同为 1
- 取反 `~`：在补码的基础上进行取反
  - 正数取反：补码（原码）→ 取反 → 补码逆运算 → 反码逆运算 → 转成十进制
  - 负数取反：原码 → 反码 → 补码 → 取反 → 转成十进制（不需要逆运算）
- 左移 `<<`：将补码全部左移，空出的补 0，超出范围的丢弃
  - 注意：有符号的，移位之后，如果最高位是 1，需要逆运算
- 右移 `>>`
  - 逻辑右移：补码全部右移，空出的补 0，超出丢弃
  - 算术右移：原始数据的符号位是 1，右移后补 1，否则补 0
  - 注意：标准规定，无符号整型都是逻辑右移；有符号的整型，是逻辑右移还是算术右移，取决于编译器

### 6. 数据类型转换

#### （1）自动类型转换（发生在编译阶段）

- 运算时会自动类型转换：运算符两边必须转成相同类型，以字节大的类型为主
- 赋值转换：赋值号左边的数据转成右边的类型
- 输出转换

#### （2）强制类型转换

- 语法：`(数据类型)(表达式)`
- 注意
  1. 要加小括号
  2. 转换之后不影响原始数据的数据类型和值
  3. 不遵循四舍五入

## 十、程序的流程控制

### 1. 顺序结构（默认）

### 2. 分支结构

- **单分支**：`if(条件表达式) { ...... }`
- **双分支**
  - `if(条件表达式) { ...... } else { ...... }`
  - 三目运算符：`条件表达式 ? 表达式1 : 表达式2`
  - 注意：if 双分支和三目运算符可以相互转换
- **多分支**
  - `if(条件表达式1) { ...... } else if(条件表达式2) { ...... } else { ...... }`
  - `switch(表达式) { case value: ...... }`
  - 注意 1：switch 的 case 语句后，要加上 break，用来终止程序
  - 注意 2：当表达式为布尔时，使用 if 多分支；当表达式为某个值时，用 switch
  - 注意 3：switch 支持的数据类型：int、char、枚举类型

### 3. 循环结构

- **作用**：重复执行某些代码块
- **while 循环**
- **do while 循环**
- **for 循环**
- **循环嵌套**：双重循环，可打印 99 乘法表
- **跳出循环的关键字**
  - `break`：跳出整个循环
  - `continue`：跳出当次循环，继续执行下一次循环
  - `goto`：跳转，非必要不建议使用

## 十一、函数

1. **概念**：用来重复执行一些具有特定功能的代码块
2. **使用**
   - **定义（封装）**
     - 语法：`int func(int num) { 函数体逻辑代码块 }`
     - 注意 1：函数的定义不能重复
     - 注意 2：定义时不会执行函数体，只有调用的时候才会执行
   - **调用**
     - `函数名(实参);`，函数的调用是可以重复的
     - 注意：函数一般需要声明，用 `extern` 关键字（可省略）
3. **函数的分类**
   - 按谁定义进行分类：库函数、自定义函数、操作系统函数
   - 按参数分类：带参函数、不带参函数
   - 按有无返回值：有返回值函数、无返回值函数（`void`）
4. **局部变量和全局变量的区别**
   1. 在函数内部定义的变量叫局部变量，在函数外部定义的变量叫全局变量
   2. 局部变量只在当前函数体内有效，全局变量在整个程序中有效
   3. 局部变量的生命周期到函数执行完毕自动释放（销毁），全局变量的生命周期是永久的，过多会造成内存泄漏
5. **多文件编程**，会操作

## 十二、数组

1. **概念**：用来存储一组具有相同数据类型的数据
2. **数组元素**：组成数组的数据，数组元素默认有下标（索引），从 0 开始，最大索引值是数组长度 - 1
3. **数组长度**：例如 `sizeof(arr) / sizeof(arr[0])`
4. **数组遍历**：获取到数组的每一个元素，用 for 循环实现
5. **数组的初始化**：`int arr[3] = {1, 2, 3};`
6. **数组名**：是一个地址常量，是数组首元素的地址
7. **数组应用**：数组作为函数的参数

## 十三、字符数组与字符串

- **区别**：以 0 或者 `'\0'` 结尾的字符数组，才叫字符串
- **字符串可以直接初始化**：`char str[] = "admj";`
- **字符串的输入输出**
  - 输入：`scanf()` 输入各种类型，字符串中间不能有空格；`gets()` 只用来输入字符串，字符串中间可以有空格
  - 输出：`printf()` 输出各种类型，默认不自动换行；`puts()` 只用来输出字符串，默认自动换行
- **字符串常用的库函数**
  - 前提：需要引入头文件 `string.h`
  - `strlen()`：返回字符串的长度
  - `strcpy(dest, src)`：字符串的拷贝，返回目标字符串的地址
  - `strcat(dest, src)`：字符串的合并，返回目标字符串的地址
  - `strcmp(src1, src2)`：比较两个字符串是否相等
